# Roselia: Misión Fotosíntesis

Videojuego educativo corto para feria científica. El jugador controla a Roselia y completa una secuencia de misiones dentro de una planta para reactivar la fotosíntesis.

## Versión 1

Incluye:

- pantalla de inicio;
- movimiento con WASD y flechas;
- controles táctiles básicos;
- Misión 1: recolectar agua en la raíz;
- Misión 2: subir por el tallo;
- Misión 3: conseguir CO₂ en los estomas;
- Misión 4: activar receptores de luz;
- Misión 5: activar el cloroplasto;
- Misión final: La Gran Sombra;
- diálogos de Roselia;
- HUD de agua, CO₂ y luz;
- pantalla final con resumen de la fotosíntesis.

## Ejecutar

No requiere instalación.

Abre `index.html` en un navegador moderno.

También puede servirse con cualquier servidor estático, por ejemplo:

```bash
python -m http.server 8000
```

Luego abre `http://localhost:8000`.

## Controles

- WASD o flechas: movimiento.
- E: interactuar con receptores y cloroplasto.

## Objetivo de diseño

La partida está pensada para durar aproximadamente 3 a 5 minutos y ser fácil de comprender durante una feria científica.
